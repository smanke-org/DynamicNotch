# DynamicNotch

Drive the app with `notch` (`notch help`). See `.claude/skills/notch/SKILL.md`. Agent commands live in
`Sources/DynamicNotch/Agent/AgentCommands.swift`; test them on a Debug build with `APP_STORE=/tmp/<name>`,
which starts a test copy with its own settings and no notch on screen (Release builds ignore it).
